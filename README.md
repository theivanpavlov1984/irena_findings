# Irena | Находки

Витрина персонального байер-сервиса: премиальные сумки и украшения под заказ,
с проверкой подлинности и доставкой.

Каталог статический — лоты хранятся в репозитории и редактируются через
headless CMS. Бронь и заявки уходят в личные сообщения Telegram: онлайн-оплаты
и корзины на сайте нет, это витрина, а не магазин.

**Прод:** [irena-findings.vercel.app](https://irena-findings.vercel.app)

---

## Стек

| Технология                  | Зачем                                                      |
| --------------------------- | ---------------------------------------------------------- |
| **Next.js 14** (App Router) | маршрутизация, статическая генерация страниц, SEO-метатеги |
| **React 18**                | UI, хуки, контекст                                         |
| **next/image**              | автоматическая конвертация в WebP и адаптивные размеры     |
| **lucide-react**            | иконки                                                     |
| **Pages CMS**               | редактирование каталога без доступа к коду                 |
| **ESLint + Prettier**       | статический анализ и единый стиль кода                     |
| **Vercel**                  | хостинг и деплой по push в `main`                          |

Стили — инлайновые объекты и один блок `<style>` в корневом компоненте.
Дизайн-токены (палитра, шрифты, кнопки) вынесены в `src/constants/theme.js`.

## Как устроен каталог

Каждый лот — отдельный JSON-файл в `src/data/lots/`:

```json
{
  "id": "hermes-bolide",
  "order": 0,
  "cat": "bags",
  "brand": "Hermès",
  "collection": "Bolide",
  "type": "Сумки через плечо",
  "model": "Bolide",
  "price": 330000,
  "condition": "Отличное",
  "status": "available",
  "specs": { "color": "…", "size": "…", "complect": "…" },
  "auth": "entrupy",
  "photos": ["/photos/Hermes_Bolide_01.jpg"],
  "desc": "…"
}
```

Правки вносятся через **Pages CMS** (конфигурация — `.pages.yml`): каждое
сохранение создаёт коммит, Vercel пересобирает сайт автоматически.

Порядок вывода задаёт `lib/lots.js`: сначала поле `order` по возрастанию,
при равенстве — новые лоты выше по `addedAt`, затем стабильная сортировка по `id`.

Списки фильтров — бренды, коллекции, категории, металлы — **строятся из самих
лотов**, а не задаются вручную. Новое значение в CMS автоматически появляется
в фильтре.

## Особенности реализации

**Статическая генерация.** Каждая страница лота собирается заранее в HTML
(`generateStaticParams`), поэтому контент виден поисковикам и открывается
мгновенно.

**Превью ссылок.** У страницы лота собственные Open Graph теги: при отправке
ссылки в Telegram или WhatsApp разворачивается карточка с фото, моделью и ценой.

**Оптимизация изображений.** `next/image` отдаёт WebP нужного размера под
устройство. Исходные JPEG в репозитории не меняются.

**Синхронизация состояния с URL.** Фильтры и открытый лот отражаются в адресной
строке (`/catalog/jewelry?brand=Cartier`), работает кнопка «Назад» в браузере —
ссылку на отфильтрованную подборку можно переслать.

**Шрифты** вынесены в отдельные `.woff2` вместо base64 в бандле, подключены
с `font-display: swap` и предзагрузкой основных начертаний.
